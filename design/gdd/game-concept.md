# Game Concept: 철갑 원정대: 강철 소대 (가제)

*Created: 2026-10-28*
*Status: Draft*

> 원작 웹게임 「철갑 원정대」(reset980reset980/tank-commander) 문서를 참고해 Unity로 새로 만드는 게임이다.
> 원작 저장소는 읽기만 했고 수정하지 않았다. 원작의 검증된 시스템(갈림길 원정, 화상·포병 덱 계열,
> 유물, 위협 단계, 끝없는 원정)과 밸런스 기록을 설계 출발점으로 쓴다.

---

## Elevator Pitch

> 탱크 3대로 소대를 꾸려 갈림길 전선을 돌파하는 덱빌딩 로그라이트.
> 머리로 덱과 진형을 짜고, 손으로 "완벽 장전"을 터뜨린다.

10초 시험: "슬레이 더 스파이어인데, 탱크 3대를 앞·뒷줄에 세우고 공격 카드는 타이밍 맞춰 직접 쏜다" — 통과.

## Core Fantasy

**내가 꾸린 탱크 소대의 사령관이자 포수.**
작전판 위에서 덱·진형·유물을 냉정하게 계산하고, 결정적인 순간에는 직접 방아쇠를 당겨
"철컥 — 쾅!" 하고 적 장갑을 부순다. 계획이 맞아떨어진 쾌감과 손으로 명중시킨 쾌감이 한 번에 터지는 경험이
다른 덱빌더에서는 얻을 수 없는 약속이다.

---

## Unique Hook

**"슬레이 더 스파이어 같은데, 그리고 또 — 탱크 3대 소대가 앞·뒷줄에 서고, 탱크가 쓰러지면 그 탱크의 카드가 덱에서 잠기며,
공격 카드는 장전 고리 타이밍에 맞춰 직접 쏜다."**

- **진형:** 앞줄 1칸 · 뒷줄 2칸. 적은 앞줄을 먼저 노린다. 격파된 탱크의 카드는 쓸 수 없게 된다. 단, 손실은 전술을 바꾸지만 판을 끝내지는 않는다(Pillar 3).
- **완벽 장전:** 공격 카드에만 타이밍 고리가 뜬다. 놓치면 덱이 설계한 위력 100%, 금색 칸 명중이면 보너스(기준 ×1.5, 조정값). 접근성 "자동 조준" 모드는 ×1.25 고정.
- **전략 70 : 손 30.** 타이밍을 모두 놓쳐도 좋은 빌드라면 1막을 깰 수 있어야 한다.

*검토한 대안:* 탱크 1대 순수 덱빌딩(콘셉트 1), 소대 전술 단독(콘셉트 2), 타이밍 손맛 단독(콘셉트 3).
사용자가 세 요소를 모두 섞기로 결정했고, 대신 각 요소를 가장 단순한 형태(고정 3칸, 공격 카드 한정 타이밍)로 넣는다.

## Player Experience Analysis (MDA Framework)

### Target Aesthetics (What the player FEELS)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Challenge** (obstacle course, mastery) | 1 | 위협 단계, 정예·보스, 빌드 연구와 장전 실력의 이중 숙련 |
| **Sensation** (sensory pleasure) | 2 | 묵직한 타격감: 히트스톱, 짧은 화면 흔들림, 저음 겹치기, 장갑 파괴 연출 |
| **Discovery** (exploration, secrets) | 3 | 카드·유물·진형 시너지 발견, 새 지역과 적 |
| **Expression** (self-expression, creativity) | 4 | 소대 구성과 덱 계열(화상·포병 등)로 나만의 빌드 |
| **Fantasy** (make-believe, role-playing) | 5 | 탱크 소대 사령관 |
| **Narrative** (drama, story arc) | 7 | 지역별 짧은 배경 설정 정도 |
| **Submission** (relaxation, comfort zone) | 8 | 의도적으로 낮음(자동 사냥 없음) |
| **Fellowship** (social connection) | N/A | MVP·EA에 온라인 없음. 장기 비전에서 랭킹만 별도 결정 |

### Key Dynamics (Emergent player behaviors)

- 플레이어는 앞줄 탱크를 언제 희생하고 언제 지킬지 스스로 계산하기 시작한다.
- 덱이 한 계열로 기울면 그 계열 카드·유물을 의도적으로 쫓는다(원작에서 검증된 계열 쏠림 보상).
- 금색 칸을 맞히기 위해 고위력 카드를 아껴 두는 "결정타 연출"을 스스로 만든다.
- 판이 끝나면 결과 화면을 보고 "다음엔 포병으로" 같은 다음 계획을 세운다.

### Core Mechanics (Systems we build)

1. **갈림길 원정 지도** — 일반·정예·상점·휴식·보스 칸, 막(지역) 구조
2. **턴제 카드 전투 + 적 의도 표시** — 행동 대기열 기반, 화상·포병 등 덱 계열과 유물
3. **소대 진형** — 앞 1·뒤 2, 앞줄 우선 피격, 격파 시 카드 잠금과 회복 수단
4. **완벽 장전 타이밍** — 공격 카드 한정, 판정 순수 함수, 자동 조준 모드
5. **수평 해금 메타 진행** — 새 카드·유물·탱크 해금만, 능력치 강화 없음

## Player Motivation Profile

### Primary Psychological Needs Served

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Autonomy** (freedom, meaningful choice) | 경로·카드 보상·진형·유물 선택이 모두 플레이어 몫 | Core |
| **Competence** (mastery, skill growth) | 빌드 이해도와 장전 실력이 둘 다 눈에 보이게 성장, 위협 단계 상승 | Core |
| **Relatedness** (connection, belonging) | 소대 탱크에 붙는 애착 정도. 온라인 교류 없음 | Minimal |

### Player Type Appeal (Bartle Taxonomy)

- [x] **Achievers** (goal completion, collection, progression) — How: 막 정복, 위협 단계, 해금 수집, Steam 업적
- [x] **Explorers** (discovery, understanding systems, finding secrets) — How: 카드·유물·진형 시너지 발견, 새 지역
- [ ] **Socializers** (relationships, cooperation, community) — How: 해당 없음(맞지 않는 대상)
- [x] **Killers/Competitors** (domination, PvP, leaderboards) — How: 자기 기록과의 경쟁(위협 단계, 최고 피해). 온라인 랭킹은 장기 비전에서 별도 결정

맞지 않는 대상: 이야기 중심 플레이어, 협동·교류 중심 플레이어, 순수 반응 액션만 원하는 플레이어.

### Flow State Design

- **Onboarding curve**: 첫 전투는 탱크 1대·카드 5장으로 시작해 장전 고리를 연습시키고(원작의 "완벽 장전 연습" 3회 성공 방식), 두 번째 전투에서 진형, 첫 정예에서 적 의도와 계열을 소개한다.
- **Difficulty scaling**: 막 안에서는 층이 오를수록, 막 정복 뒤에는 위협 단계 0~10(원작 조건 누적 방식)으로 올린다.
- **Feedback clarity**: 결과 화면(원작 F8 방식) — 덱 계열, 가장 큰 한 방, 활약 카드 3장, 유물별 기여, 장전 성공률.
- **Recovery from failure**: 패배 즉시 "바로 다시 출발". 한 판이 45분 이내라 손실이 작고, 해금이 남는다.

## Core Loop

### Moment-to-Moment (30 seconds)

카드를 고른다(전략) → 공격 카드면 장전 고리가 돈다 → 금색 칸에 맞춰 발사(손) → 히트스톱 0.2~0.4초, 짧은 화면 흔들림,
큰 피해 숫자, 적 장갑이 눈에 보이게 깨진다. 내 선택이 맞았다는 확인과 명중의 쾌감이 한 번에 온다.

### Short-Term (5-15 minutes)

전투 하나: 적 의도를 읽고 → 앞줄로 막고 뒷줄로 때린다 → 승리 후 카드 3장 중 1장 고르기.
"한 판만 더"는 "이 카드만 들어오면 화상 덱이 완성되는데…"에서 시작한다.

### Session-Level (30-120 minutes)

1막 지도 하나(약 15층: 일반·정예·상점·휴식·보스)를 30~45분에 돈다. 자연스러운 멈춤은 보스 처치나 패배이고,
다음 세션으로 잇는 고리는 결과 화면의 "다음 목표"와 새로 해금된 카드·유물·탱크다.

### Long-Term Progression

막 정복 → 다음 막 → 위협 단계 → (전체 비전) 끝없는 원정. 영구 성장은 **수평 해금만**: 선택지가 넓어질 뿐 수치는 오르지 않는다.
게임의 끝은 최고 위협 단계 정복이다.

### Retention Hooks

- **Curiosity**: 잠긴 카드·유물·탱크, 아직 못 본 지역과 보스
- **Investment**: 해금 진행, 애착이 생긴 탱크 조합
- **Social**: 해당 없음(장기 비전의 일일 고정 시드·랭킹은 별도 결정)
- **Mastery**: 위협 단계, 장전 성공률, 새로운 계열로 깨기

## Game Pillars

> 크리에이티브 디렉터 CD-PILLARS 검토(CONCERNS) 의견을 반영해 고친 뒤 사용자가 확정함 (2026-10-28).

### Pillar 1: 짜는 자가 이긴다
승패의 대부분은 덱·진형·유물 선택이 정한다.

*Design test*: 덱만으로 완성되는 카드 vs 덱·진형·유물 중 둘 이상을 엮어야 강해지는 카드 → **후자**.

### Pillar 2: 강철의 무게
모든 발사는 묵직하고 파괴적으로 느껴져야 하고, 그 무게는 시스템에도 실린다.

*Design test*: 화려하고 긴 연출 vs 짧고 굵은 타격 → **짧고 굵게**(템포 유지). 피해 숫자만 오르는 연출 vs 장갑·진형 상태가 눈에 보이게 바뀌는 결과 → **후자**.
완벽 장전 명중의 반응(히트스톱·반동·저음)이 이 기둥의 가장 중요한 산출물이다. MVP에서는 값비싼 VFX보다 히트스톱·화면 흔들림·소리 겹치기로 먼저 채운다.

### Pillar 3: 소대는 운명 공동체
탱크 3대의 위치와 생존이 덱과 전술을 바꾼다. 탱크의 개성은 소대 안의 역할로 표현한다.

*Design test*: 어느 칸에서 써도 같은 카드 vs 칸·생존 상태에 따라 가치가 바뀌는 카드 → **후자**.
원칙: **잃은 탱크는 전술을 바꾸지만 판을 끝내지는 않는다**(악순환 방지 — 구체 수단은 game-designer가 GDD에서 정의).

### Pillar 4: 한 판만 더
한 판은 45분 이내이고, 매 판 다른 빌드와 분명한 다음 목표가 있다.

*Design test*: 영구 성장 vs 판 안에서의 선택 → **판 안의 선택이 먼저**.
경계: **영구 진척은 선택지를 넓히는 해금(수평)만 한다. 능력치를 올리는 강화(수직)는 하지 않는다.**

### Anti-Pillars (What This Game Is NOT)

- **NOT 돈으로 사는 능력치**: 원작의 이벤트 탱크 ×1.15 같은 배율을 넣지 않는다. 장기 비전의 뽑기는 외형·수평 해금 전용일 때만 허용한다 → Pillar 1 보호.
- **NOT 타이밍 실패만으로 지는 설계**: 놓치면 100%, 맞추면 보너스. 타이밍을 다 놓쳐도 좋은 빌드라면 1막을 깰 수 있다 → 전략 70 : 손 30과 Pillar 1 보호.
- **NOT 시간 때우기 반복**: 자동 사냥·노가다 성장이 없다 → Pillar 4의 긴장감 보호.
- **NOT MVP의 온라인 기능**: 길드·랭킹·채팅을 넣지 않는다 → 범위가 넘치면 Pillar 1·2의 품질이 무너진다.

## Visual Identity Anchor

> 아트 디렉터 AD-CONCEPT-VISUAL 검토(CONCEPTS, 3방향) 중 사용자가 "작전 지도 바탕 + 무쇠와 화약 타격 순간" 조합을 선택함.

**방향 이름:** 작전 지도 × 무쇠와 화약 (War Table × Iron & Cordite)

**한 줄 시각 규칙:** "계획하는 동안 모든 것은 작전판 위의 말처럼 한눈에 읽히고, 쏘는 0.3초 동안만 강철과 화약이 화면을 지배한다."

**보조 원칙**
1. **정보 색은 신성하다** — 아군 의도·선택·장전 고리 = 앰버/노랑, 적 의도 = 적색, 방어 = 청백색. 정보 색은 조명의 영향을 받지 않는다(unlit 오버레이). *설계 판단*: 지역 분위기를 위해 정보 색을 바꾸고 싶을 때 → 바꾸지 않는다.
2. **역할은 실루엣으로 읽힌다** — 전열 탱커는 넓고 낮은 사다리꼴, 후열 포격형은 긴 포신, 지원형은 안테나·돌출부. 앞 1·뒤 2 칸은 바닥 스텐실로 늘 보인다. *설계 판단*: 멋진 디테일과 실루엣 구분이 충돌할 때 → 실루엣.
3. **피해는 모델에 남는다** — 장갑 탈락 → 연기 → 화염의 3단계로 체력바를 보지 않아도 소대의 위기가 읽힌다. *설계 판단*: 피해를 숫자로만 보여 줄지 모델에도 남길지 → 모델에도 남긴다(Pillar 2·3).

**색 철학:** 계획 화면은 바랜 올리브·종이 베이지·흑연 회색의 무채색 바탕에, 색은 정보로만 쓴다. 사격 순간에만 포구 화염과 폭발의 주황~백색이 화면에서 가장 밝고 채도 높은 색이 된다. 정적인 바탕이 있어야 폭발이 무겁다. 10개 지역은 바닥색·조명색·소품 2~3종 교체로만 구분한다.

**제작 원칙:** CC0 로우폴리 3D 팩 + 팔레트 텍스처 아틀라스 + URP 단순 툰/플랫 셰이딩. 적도 3D로 통일한다(웹판의 2D 회화풍 적과 섞지 않음). 상업적 차별화는 모델이 아니라 팔레트 규칙·조명·타격 연출에서 만든다.

*검토한 대안:* 방향 C 「전선의 포스터」(지역 개성 최강, 1인 제작 비용·일관성 위험 최대), 방향 B 단독(타격감 최대, 어두운 지역 가독성 위험), 방향 A 단독(가장 저렴, 묵직함 약화 위험).

## Risks and Open Questions

### Design Risks
- 탱크를 잃으면 덱이 약해지는 악순환 → "손실은 판을 끝내지 않는다" 원칙과 회복 수단(구조 카드·견인·잠긴 카드의 대체 효과 등)을 GDD에서 정의.
- 세 요소(덱·진형·타이밍)를 처음 배우는 부담 → 단계별 온보딩(Flow State Design 참고).
- 타이밍 보너스 ×1.5와 자동 조준 ×1.25가 전략 70 : 손 30을 실제로 지키는지 → 시뮬레이션과 플레이테스트로 검증("타이밍 전부 실패해도 좋은 빌드로 1막 정복").
- 타격 연출이 길어지면 한 판 45분을 넘을 위험(Pillar 2 vs 4).

### Technical Risks
- Unity 첫 프로젝트: 씬·프리팹·직렬화·UI·셰이더 그래프 학습에 1~2주.
- 히트스톱을 `Time.timeScale`로 만들면 타이밍 고리가 같이 멈춤 → 고리·UI 트윈은 unscaled time, 판정은 입력 이벤트 시각 기반 순수 함수.
- 저장: 지도 칸 사이에서만 저장, 에셋은 문자열 ID로, 직렬화 가능한 자체 난수, 저장 형식 버전 필드. `JsonUtility` 대신 Newtonsoft 패키지 권장.
- 카드 손패 UI(uGUI vs UI Toolkit)를 일찍 결정해야 함(ADR 대상).
- 이 클라우드 작업 공간에서는 Unity를 실행할 수 없음 → 실행·화면 캡처는 사용자 PC에서 하고 `production/qa/evidence/`에 올리는 절차를 정함. 순수 C# 전투 코어는 클라우드에서 `dotnet test`로 검증 가능. GameCI는 나중에 결정.

### Market Risks
- Steam 덱빌더 시장 포화 — "또 하나의 슬레이 더 스파이어"로 보일 위험. 진형 + 타이밍이 첫 영상·스크린샷에서 바로 보여야 함.
- CC0 범용 에셋의 첫인상 — 팔레트 규칙·조명·타격 연출로 차별화.

### Scope Risks
- 프로듀서 PR-SCOPE 판정 OPTIMISTIC: 원래 MVP 3~5주는 1인·Unity 첫 프로젝트·rigor `full` 조건에서 6~9주가 현실적(낙관 5 / 기대 7 / 비관 10+주, 신뢰도 낮음). rigor `full`의 문서·검증 비용이 개발 시간의 25~35%.
- 사용자 결정(2026-10-28): **수직 단면 우선**으로 조정하고 rigor `full`은 유지.
- 타이밍 고리와 타격감은 줄이면 안 되는 항목(차별점). 줄일 수 있는 것은 카드·적 수와 해금.
- 장기 비전의 뽑기·온라인 랭킹은 백엔드·결제·확률 공개 규제·부정행위 방지 부담 → 별도 결정 항목.

### Open Questions
- 타이밍 고리 손맛이 실제로 좋은가, 금색 칸 폭은 얼마인가? → 0주차 기술 시험(회색 상자 전투, 사용자 PC).
- 격파 시 카드 잠금이 재미있는 긴장인가, 답답한 벌칙인가? → 수직 단면 플레이테스트.
- 탱크 3대의 역할 구분(중전차/구축전차/자주포)이 진형 선택을 의미 있게 만드는가? → `/design-system`과 플레이테스트.
- 가격과 출시 경로(Next Fest 데모 → Early Access)는? → 수직 단면 이후 결정.

## MVP Definition

**Core hypothesis**: "플레이어는 덱·진형을 짜고 완벽 장전으로 마무리하는 전투를 30분 넘게 즐기고, 끝나면 '한 판만 더'를 누른다."

**Required for MVP**:
1. 갈림길 지도 1막(약 15층: 일반·정예·상점·휴식·보스)
2. 턴제 카드 전투 + 적 의도 표시 + 카드 약 30장(화상·포병 계열 포함)
3. 소대 진형(앞 1·뒤 2, 시작 탱크 3대 고정: 중전차·구축전차·자주포), 격파 시 카드 잠금과 회복 수단
4. 완벽 장전 타이밍(공격 카드 한정) + 자동 조준 모드
5. 적 6종 + 정예 2 + 보스 1, 유물 10개
6. 묵직한 타격감(히트스톱·화면 흔들림·소리 겹치기)
7. 결과 화면 + 몇 가지 수평 해금 + 로컬 저장

**Explicitly NOT in MVP** (defer to later):
- 2막 이후 지역, 위협 단계, 끝없는 원정
- 탱크 수집·교체(9대 이상), 오늘의 작전(일일 시드)
- 3D 직접 운전 대전, 뽑기, 시즌 패스
- 온라인 기능 전부(길드·랭킹·채팅·친구 대전)
- 전투 중 저장

### Scope Tiers (if budget/time shrinks)

| Tier | Content | Features | Timeline |
| ---- | ---- | ---- | ---- |
| **0주차 기술 시험** | 회색 상자 전투 1개 | 타이밍 고리 · 히트스톱 · 툰 셰이더 | 3~5일 |
| **Vertical Slice** | 5층 · 탱크 3대 · 카드 12~15장 · 적 3종 + 정예 1 | 핵심 전투 + 진형 + 타이밍 + 타격감 | 2~3주 |
| **MVP** | 1막 15층 · 카드 약 30장 · 적 6 + 정예 2 + 보스 1 · 유물 10 | 위 + 결과 화면 · 수평 해금 · 로컬 저장 | +4~5주 |
| **Alpha / Early Access** | 3막 · 탱크 9대 · 카드 약 120장 · 유물 40개 | 위협 단계 0~10 · Steam 업적 | +4~6개월 |
| **Full Vision** | 10막 + 끝없는 원정 · 탱크 18대 | 오늘의 작전 · (별도 결정) 외형 뽑기 · 온라인 랭킹 | +6~12개월 |

컷 순서(시간이 모자랄 때): 해금 → 유물 수 → 카드·적 수. **타이밍 고리와 타격감은 컷하지 않는다.**
